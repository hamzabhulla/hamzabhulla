## Featured work

### VibeTalk — real-time chat with voice notes and calls

A full-stack messaging app: direct messages and group rooms, voice notes, WebRTC voice/video calls, reactions, read receipts, and push notifications.

- Authorization enforced with Supabase Row Level Security and authenticated server functions, not browser checks
- Optional end-to-end encrypted group text, WebRTC calls, and Web Push with a service worker
- Deploys to Cloudflare Workers and Vercel, with build guards that prevent shipping stale output
- **Stack:** React 19 · TypeScript · TanStack Start · Supabase · Tailwind CSS

**[Live demo](https://vibetalk.hamzabhulla.workers.dev)** · **[Source](https://github.com/hamzabhulla/VibeTalk)**

### Web Notepad — local-first notes with drawing and sync

A browser-based notepad for rich-text notes, checklists, sketches, and quick capture. It works offline and installs as an app.

- Local-first storage with optional cloud sync between devices
- One undo history covering text, checklists, shapes, and page size
- Shapes and freehand drawing, page sizes, print and PDF export
- **Stack:** Vanilla JavaScript · Vercel Functions · Upstash Redis · PWA

**[Live demo](https://easynotepad.vercel.app)** · **[Source](https://github.com/hamzabhulla/web-notepad)**

### Ember & Co. — restaurant ordering platform (in development)

A restaurant web platform that combines a customer-facing ordering experience with tools for running the restaurant. It is under active development.

- Planned scope: menu, cart, checkout, order tracking, and an admin panel for restaurant operations
- Responsive interface built as a typed single-page app
- **Stack:** React · TypeScript · Tailwind CSS · Vite · Supabase
